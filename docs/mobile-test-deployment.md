# 手机测试包：给部署人员与项目负责人

## 先看边界

本包是苹果Safari、华为系统浏览器试用的静态网页/PWA，不是APK、IPA或鸿蒙HAP；不能把ZIP直接发给苹果安装。没有购买或开通托管、没有上线链接、没有真机测试结论。首次访问需要HTTPS静态托管，部署完成后把链接发给阿姨；不需要自建业务服务器才能看此演示。

只用虚构数据，无账号权限、真实收款、云数据库、通知或多端同步。localStorage仅保留当前浏览器测试状态，不能保管真实营业资料。两台手机显示不同进度是预期行为。免费/收费静态托管及其在门店网络的可达性要选定后核实；没有承诺某服务免费或稳定。

## 包里有什么

- `site/`：完整静态站点，包括五页流程、桌面图标、manifest、离线缓存脚本及手机说明。
- `DEPLOYMENT.md`：本说明。
- `release.json`：版本、文件大小、SHA-256，不含客户资料。

没有旧软件源码、数据库、备份、私人文件、node_modules或密钥。不要上传整个开发仓库，只上传site内容。

## 部署步骤

1. 选择一个能服务普通静态文件的HTTPS托管环境。账号开通、条款接受和费用由负责人确认；本包不绑定厂商。
2. 解压ZIP，把`site`设为发布目录；网站根目录直接是index.html，不是ZIP、不包含额外site层。若托管界面只接收ZIP，可将site内部文件另压成它要求的格式。
3. 不需要npm安装、数据库或运行构建命令；这些是已经生成的网页资产。必须同时上传所有文件，建议托管平台使用原子部署。
4. 服务器必须以JavaScript MIME提供`.mjs`和`sw.js`，manifest以`application/manifest+json`提供，PNG/SVG以相应图片类型提供。不能把缺失文件都重写成index.html。未知路径应404。
5. 启用HTTPS。`_headers`仅在支持此格式的托管商生效；其他服务器需手动配置同等响应头。建议所有文件Cache-Control:no-cache，尤其sw.js；Service Worker的版本缓存由脚本管理。CSP不代替登录保护，本演示仍可被任何获得链接的人打开。
6. 每个测试站点用独立来源/目录，不覆盖已有营业站。若部署子目录，URL结尾保留`/`，相对资源与SW scope需保持在该目录。首次优先部署独立站点根路径。
7. 先通过下列验收，再把正式HTTPS测试链接发到她手机。不要发localhost、127.0.0.1、局域网IP或依赖开发电脑的临时穿透链接冒充独立部署。

## 手机安装入口

苹果：Safari打开HTTPS地址，分享→添加到主屏幕；如有“作为Web App打开”，开启后添加。华为：系统浏览器打开地址，菜单查找“添加至桌面”，没有则先收藏。具体机型/系统/浏览器版本待提供，桌面图标、独立窗口、离线缓存必须真机检查，不能因为写了manifest就宣称全部支持。

从桌面入口联网打开一次，等待“页面缓存已就绪”，再试飞行模式。浏览器/桌面入口存储可能分离；系统清理缓存、隐私模式、空间不足均可能影响保留。缓存未就绪不能承诺离线打开。

## 部署后必做验收（尚待外部环境执行）

1. 开发电脑关机，苹果和华为均用移动网络打开链接，五页可访问。
2. 每台独立操作演示订单，刷新、关闭重开保持本机进度；另一台不自动变化。
3. 点击重置先取消，进度不变；确认后仅本机回到初始状态。
4. 添加桌面图标，从图标联网打开后，飞行模式重新进入五页。若失败记录手机、系统、浏览器、操作截图。
5. 试独立宠物进度、取消/确认收款、寄养延住冲突、客人待确认、往返分段。全部是虚构动作。
6. 在线发布下一包时，已有页面出现更新按钮；点更新会刷新并丢弃未提交的表单，已保存且兼容的本机测试状态保留。未点击时可继续当前缓存版本。升级流程需真机验证。
7. 检查浏览器无资源404/MIME错误；`/.git/config`、`/salon.db`均不可下载，包内无真实资料。

## 生成下一包（开发电脑）

在E:\Pet-store运行：

```powershell
node --test tests/*.test.mjs
powershell -NoProfile -File scripts/package-mobile-test.ps1
```

若Windows PowerShell不支持环境中的脚本能力，使用已安装的PowerShell 7 `pwsh -NoProfile -File scripts/package-mobile-test.ps1`。打包脚本创建时间戳目录与ZIP，不覆盖旧包，逐ZIP条目核对SHA-256。只把新包site内容完整替换到托管发布目录；保留旧包用于回退，不把浏览器本地演示进度当作云备份。
