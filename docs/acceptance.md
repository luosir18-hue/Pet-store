# 验收草案与执行边界

阶段0只有内存原型和只读检查。以下 A01～A30 全是待后续实现的业务验收，当前均 **未执行**，不能用原型测试替代。所有金额/容量为虚构测试夹具，非店内经营规则。

额外资金边界：负数、NaN、超上限、超过两位小数、币种不符、篡改报价、余额刚好够/差1分。角色拒绝测试涵盖读写与文件。日期覆盖相邻半开区间、清洁缓冲、跨日、同日寄养和确认的计费政策。

## 阶段0本地验收

- P01：今天打开订单，按宠物开始/完成，付款和交还不被自动改变。
- P02：订单演示收款必须明确核实勾选；取消不登记；重复确认不重复收款。
- P03：客人预约按接送/寄养展开字段；提交只显示待确认，能在老板今天页看到申请摘要。
- P04：寄养尝试冲突延住显示失败，旧日期不变；无冲突延住更新日期；照护必须输入实际记录。
- P05：接送去程完成，返程仍待安排；两个行程分别推进；页面不展示钱包。
- P06：刷新重置虚构数据；窄屏无页面横向溢出；键盘可操作控件。
- P07：本地HTTP仅白名单原型文件，/.git/config、/work/*、原始库及未知路径不可读取；POST拒绝。

这些只验证交互模型、静态文件边界，不证明真实身份权限、并发锁、余额、短信/通知或支付能力。具体运行结果见 progress。
