给阿姨的试用说明

第一次打开

请用 Safari（苹果）或华为系统浏览器打开部署后的 HTTPS 链接。ZIP 是交给部署人员的，不是手机安装包；电脑上的127.0.0.1链接也不能发给另一台手机使用。

苹果：分享 → 添加到主屏幕；华为：浏览器菜单 → 添加至桌面（机型不同可能没有此项，先收藏也可以）。

添加后从桌面图标联网打开一次，等待“页面缓存已就绪”，再试飞行模式重开。缓存可被手机系统清理，离线能力不保证永久有效。

试这五件事

  1. 今天工作台 → 打开订单，只开始或完成豆包的服务；看糯米是否保持原状。
  2. 核实并登记演示收款，试一次取消、一次确认；不会真的扣钱。
  3. 客人预约 → 选寄养、往返接送，填写示例地点。提交后仍是“待老板确认”。
  4. 寄养 → 试有冲突的延住，原日期应不变；填写一句虚构照护。
  5. 接送 → 操作接来的一段，送回那一段应保持原状。

再检查是否能离开电脑

  1. 部署人员提供真正的 HTTPS 链接，不是本机或临时穿透链接。
  2. 把开发电脑关机，手机使用流量仍能首次打开链接。
  3. 关闭页面再打开，当前浏览器的演示进度应保留；保存失败会在页面提示。
  4. 缓存就绪后开飞行模式，重新进入五个页面试操作。

这两台手机不会同步！每台只保存自己的演示数据。这里没有账号、正式账本、客户通知或云备份。浏览器和桌面入口的存储是否共用也要在真机验证。

请勿填客户姓名、电话、家庭地址、真实照护情况或余额。日期和价格都是固定示例。想重新试，用“重置演示”，确认后只重置本机记录。

怎么反馈

告诉开发人员：手机型号、系统版本、使用的浏览器、点了哪几个按钮、期待什么、实际出现什么；可发不含私人资料的截图。先反馈字是否够大、按钮是否顺手、流程有没有多余步骤。
